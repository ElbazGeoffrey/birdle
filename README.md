# birdle

This is just a pretty small project intended to serve as an introduction to Dart and Flutter.

The game is a simple mastermind game.

# how to play

To start the project :

- Follow the Flutter installation guide at that link : https://docs.flutter.dev/install/quick?_gl=1%2A1dh5cq9%2A_ga%2AMzQ0NDIxOTgyLjE3NzA5ODUzNDA.%2A_ga_04YGWK0175%2AczE3NzE1MDg2OTUkbzE1JGcxJHQxNzcxNTA4NzEzJGo0MiRsMCRoMA..
- Clone the project anywhere you'd like
- Go in the main folder and run :
  - If you have Chrome : flutter run
  - If you don't have Chrome : flutter run -d web-server
